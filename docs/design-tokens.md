# FocusGarden Design Tokens & Assets

## Color Palette
- **Dark Brown (`#4c2802`)**: Major text, outlines, logo, dirt color, button color, sign color, active Home button.
- **Light Brown (`#8c4c0c`)**: Sign post.
- **Beige (`#f7f3ec`)**: Background for popups, text color for buttons.
- **Green (`#7ab85f`)**: Grass color (Garden page bottom 2/3rds).
- **White (`#f3f3f3`)**: Background of text boxes where users type tasks.
- **Blue (`#c9ecf9`)**: Sky color.
- **Light Grey (`#b7b7b7`)**: Sign post (deactivated/grayed out).
- **Dark Grey (`#666666`)**: Sign (deactivated/grayed out).
